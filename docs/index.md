## Where to start

- {doc}`install`: build pyoptics from source into a virtual environment.
- {doc}`modules`: what each module does and how mature it is.
- {doc}`conventions`: phase signs, FFT centering and sign rules used
  throughout. Read this before comparing results with a textbook.
- {doc}`examples`: 95 notebooks with figures, one per topic, most of them
  comparing the numerics with analytic results.
- {doc}`learning_paths`: suggested reading orders through the notebooks for
  students, lens designers, lithography, illumination and laser engineers,
  metrologists, computational electromagnetics and developers.
- {doc}`api/index`: every module, class and function.
